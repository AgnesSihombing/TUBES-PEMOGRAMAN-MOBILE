# TUBES-PEMOGRAMAN-MOBILE

FNB App

FNB App merupakan aplikasi mobile Food and Beverage yang dibuat untuk memudahkan pengguna dalam melihat menu makanan dan minuman serta melakukan pemesanan.

Aplikasi ini dikembangkan sebagai tugas mata kuliah Pemrograman Mobile.

Fitur
Customer
Melihat daftar makanan dan minuman
Melihat detail menu
Menambahkan menu ke keranjang
Mengatur jumlah pesanan
Melihat total harga
Melakukan pemesanan
Menu
Menampilkan berbagai pilihan makanan dan minuman
Menampilkan nama, harga, dan informasi menu
Menampilkan detail dari setiap menu
Keranjang
Menampilkan item yang dipilih
Menambah atau mengurangi jumlah item
Menghapus item dari keranjang
Menghitung total harga pesanan
Teknologi
Kotlin
Android Studio
Jetpack Compose
Git & GitHub
Tujuan

Aplikasi ini dibuat untuk menerapkan konsep dasar pengembangan aplikasi mobile, mulai dari pembuatan user interface, navigasi antar halaman, pengelolaan data, hingga proses pemesanan makanan dan minuman.
