# 📢 Laporin — Campus Facility Reporting App

Laporin adalah aplikasi Android yang memudahkan mahasiswa melaporkan kerusakan fasilitas kampus dan membantu admin mengelola serta memantau tindak lanjut pengaduan.

## 👥 User Roles

🎓 **Mahasiswa**
- 🔐 Registrasi dan login
- 📝 Membuat laporan kerusakan fasilitas
- 📸 Mengunggah foto kerusakan
- 📋 Melihat riwayat pengaduan
- 🔎 Memantau status laporan

🛠️ **Admin**
- 🔐 Login sebagai admin
- 📑 Melihat seluruh laporan
- 🔍 Melihat detail pengaduan
- 🔄 Memperbarui status laporan
- ✅ Menandai laporan yang selesai ditangani

## 🛠️ Tech Stack
- 💻 Kotlin
- 🎨 Jetpack Compose
- 🔥 Firebase Authentication
- 🗄️ Cloud Firestore
- 📸 Firebase Storage
